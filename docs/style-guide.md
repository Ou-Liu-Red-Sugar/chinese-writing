# 默认写作原则

这份公开维护版整理了项目形成时的表达偏好，适用于中文教材、说明、技术文章和研究报告。使用者的具体任务与项目要求优先；文学创作保留作品自己的声音。

## 内容与读者

从读者尚未理解的关系开始。已经掌握的概念直接调用，把篇幅用于新的事实、机制、推导、区别、条件和证据。复杂内容可以充分展开，简短任务直接完成；不以字数少、句子短或段落等长作为目标。

材料支持什么，就表达什么。事实、来源主张、假设、预测和研究判断的区别在会影响理解或采用时说明。未知只限制相关命题，不能把未披露写成不存在或已经出现缺陷。

## 句子与篇章

开篇进入对象、关系或实际问题。安排读者依次认识什么，把篇幅放在需要解释的关系上，并在相应位置使用例子和对照。第1版草图就把这些安排写成段落、实际衔接句和标点骨架，不等成稿再补“起承转合”。

“现在，让我们……”“考虑……”“设……”“记……”可以承担推广、设定或比较的实际功能。按上下文判断其作用，既不机械禁用，也不把它们复制成每段的固定开头。

具体名词和能描述实际动作的动词优先。叙述已知操作时直接写谁做什么，语态和语序仍依本句重点选择。抽象名称应当帮助区分或解释，术语与符号保持稳定。检查主语、省略、修饰范围、词序、长从属部分和名词化，同时判断分句怎样组成一项完整表达。

用读者熟悉的说法组织自然讲解。先看前句交代了什么、后句接着回答什么，再安排句序、条件与主句、实际观察与一般说明的层级。根据这些关系选择“如果……就……”“等到……再……”等完整表达，也留意“首先、会、就、还、已经”承担的顺序、情态和进展。连同动词、回指和停顿一起读，保留有作用的字，不以能猜出大意作为充分标准。具体沿[句群重组方法](../references/sentence-construction.md#从分句关系重组句群)处理，不按用词数量评价。

内容扎实，也允许表达适度从容。铺垫、呼应、停顿和带读语气可以帮助读者跟上解释；先让整段完整、自然地展开，再删去重复或拖慢推进的部分。不要把每个词是否提供新事实当作唯一尺度，也不为增加口语感而逐句填入同样的提示。分寸沿[完整讲解与适度从容](../references/sentence-construction.md#完整讲解与适度从容)判断。

一项认识尚未解释完，不为排版节奏拆成许多短段；对象或论证作用改变时再换段。标题用于定位实质不同的内容；列表用于并列项，表格用于同维比较，流程图用于关系或步骤。格式服务于当前内容。

## 限定与删改

删去没有增加事实、关系、条件、证据或必要交际作用的文字。防御性措辞逐命题处理：删除会改变真值、范围、证据身份、计算或行动含义的限定应保留，并贴近对应判断；其余作者减责、同义重复和泛化提醒删除。

例子应解释、证明、判别或支持操作。一个例子已经完成任务时，不继续增加没有新增理解作用的例子；改变条件、区分相近情形或检验迁移仍可需要另一个例子。结尾停在最后一项有效内容完成处，不自动添加泛用建议或服务邀请。

## 校准方式

使用具体原稿、用户示范、原始审读和实际修改来校准。把用户明确认可的范围与助手从中归纳的写法分开，新内容仍需检验。公开题、已见范文和模型读者的结果保留各自身份；不由一次好评推定所有文体都已合格。
