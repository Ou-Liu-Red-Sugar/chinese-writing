## 原稿与修订版本

所有入口应能取回完整实际文字。短任务可直接把各版放在本记录，较长任务用文件入口；摘要不能代替原稿。

| 版本 | 身份与入口 | 形成者、时间 | 改动与理由 | 状态 |
|---|---|---|---|---|
| source | 原稿／原始材料 | | 保持原文 | |
| v0 | 第0版思想与体现方式，允许图表 | | | |
| v1 | 第1版段落、衔接句、标点骨架，中间句子暂不展开 | | | |
| v2及后续 | 对第1版骨架的实际修订 | | 关联具体问题ID，按实际使用版本行 | |
| fs1 | `final_sketch` | | 验收依据、未决事项、局部填充清单 | 接受／撤销 |
| f1 | 填充正文 | | 每个空缺的实际文字与固定文字对照 | |
| r1 | 审读后版本 | | 如改动固定文字，填写回退草图与重新验收的版本 | |

`final_sketch` 核对：段落、句序、承接、主要措辞与标点是否已经确定；定义、公式、数字、单位、条件和来源是否已经固定；空缺是否仅需局部填充。记录对照方法与结果，不以修改轮数代替验收。无空缺时写明最终草图与正文一致。
