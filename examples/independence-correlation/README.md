# 独立性与不相关：一次实际写作过程

从[正文](article.md)开始阅读，或按下表查看思想安排怎样进入骨架、专项反馈怎样改变实际文字。

| 阶段 | 文件 | 内容 |
|---|---|---|
| 第0版 | [sketch-v0.md](sketch-v0.md) | 思想与体现方式，尚未生成段落和正文 |
| 第1版 | [sketch-v1.md](sketch-v1.md) | 段落及句群骨架，保留中间内容占位 |
| 专项审读 | [篇章与衔接](review-structure-v1.md)、[组句与限定](review-language-v1.md) | 两位模型执行者分别给出的实际意见 |

历史审读中引用的“写作要求第1–16节”对应 [创作者要求输入快照](../../docs/author-preferences-20260922.md)，保留原编号；当前维护版另见 [style-guide](../../docs/style-guide.md)。

完整执行记录在 [run.json](run.json)。这份样稿形成于方法v2.3；公开整理只统一路径、去除内部执行者代号，并补充授权说明，没有回写一套虚构的草图历史。`process.md`及运行记录中的“未发布”“供用户判断”等文字描述当时样稿完成时的状态，公开归档不改写这些历史判断。草图意见和文章用于观察实际选择，不构成跨模型性能评测。
