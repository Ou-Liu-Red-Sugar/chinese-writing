# 第1版到第2版的反馈处置

本轮原始反馈：review-structure-v1.md、review-language-v1.md。修改者协调者。第2版仍有9处明确的短语/分句占位，未生成正文。

| 位置及意见 | 处置 | 第2版实际变化 |
|---|---|---|
| 结构1／P2反向说明 | 采用删除建议 | 删除C03，不展开后文不使用的反向证明及零概率分支；保留正概率条件下由独立得到条件分布不变 |
| 结构2／P3转场 | 采用比较对象前置，保留语言K2的有效定义动作 | 起句明确每对取值的概率要求与一个平均数；随后“记……并定义……为：”完成均值及协方差设定 |
| 语言L1／P4 | 采用，选择行内公式方案 | “若……记……则……因而在这一条件下……”全部写入骨架；正方差仅管Pearson公式与等价，不扩大到不相关定义 |
| 结构4与语言K3／P5 | 采用具名回指，并保留有效作者引导 | 明写比较独立性与不相关；保留若/就/因此的推导入口，以“即X与Y不相关”接计算结果，不另作重复小结 |
| 结构6与语言L2／P7 | 采用 | 行内并列原概率和条件概率，以“而……；两者不同，因此……”确定句法及判别结论 |
| 结构7与语言L3／P8 | 采用 | 三个“当……时”分别列偏差乘积，以分号并列；末句从等概率平均转回给定X后的Y分布，明确比较对象，不只重说逆命题不成立 |
| 其他保持意见 | 采用 | 三节顺序、先定义后解释和计算式、单一反例同时检验两种标准、必要有限/正概率/正方差范围均保留 |

本轮特意不加入高斯分布、因果关系或抽样误差，避免把本篇的有限分布比较扩为其他专题。数学原文首个错误乘积事件和式未进入任何草图。

接续：只核三处实际修改的句群接口、范围和末段收束，随后Lead验收骨架再填充。
