# 用真实样文校准标点与行文节奏

在用户要求比较文风、现稿有持续的句界或引导问题时使用。本页把标点分布与连续句群细读放在一起，具体用法仍沿[句子方法](sentence-construction.md#7-标点与第1版的交付)，读感沿[完整讲解与适度从容](sentence-construction.md#完整讲解与适度从容)。普通短答无需每次统计。

## 1. 先确定参考文章与采用范围

选择实际读过、用途接近的原生中文文章，固定版本、正文起止和统计口径。作者论述、引用、公式、表格及网页附加内容分别辨认。学习句群的组织，不自动采用样文的事实、修辞强度、旧式用语或全部标点习惯。主文与详细版补充也分别观察。

## 2. 数值描述什么

本次频率的分母是正文中的字母与数字字符，汉字、英文字母、数字逐字符计数，空格与标点不计入分母。逗号、分号、冒号、问号、叹号按对应功能合并半角与全角；小数点、代码及公式中的符号不作停顿。引文保留在全文统计中，另看引文内外分布。

句长以句号、问号、叹号和段末切分；停顿间距另加逗号、分号、冒号作分界，顿号保留在并列成分内部。该项是表层长度描述，包含引文内部句末，不等于命题数量。成对引号、括号以及双字符破折号若另行计数，记录按字符还是按一组计算。换统计口径时重算双方，不混用每千词、每千汉字或标点内部占比。

保留篇间差异，再看其中的具体句群。《大自然的语言》的植物枚举增加了顿号；吴文的连续过程没有使用分号；《咬文嚼字》的8个感叹号全部出现在引文中。用总频率解释作者习惯前，应先分清这些来源。

写前据本篇任务选择相近样文与段落，帮助安排解释展开和停顿的尺度；写后再用分布定位集中出现的符号与句式。参考区间不规定每段的符号数量，零次不等于缺陷。短段先报告原始次数，归一化率只作粗比较；几百字里多一处冒号就会显著改变比例。样本未覆盖的文体不直接沿用这些数值。

## 3. 把统计线索改成具体编辑动作

先沿当前句群说明某个标点承担什么，再选择保留、补足、合并或重组。可采用下列从真实段落取得的操作；它们是编辑归纳，不是固定段落模板。

- **让实例完成已经提出的解释任务。** 引例提示之后立即进入材料，按读者需要区分观察、推断、行动与结果。提示可以为转换留余地，不能因下一段明显是例子就自动删除。
- **把比较维度放稳，再分组。** 两组或多组说明回答同一个问题，各组内部可充分展开；需要同句核看时用分号区分。重点一组可多解释一层，不为对称而裁平。并列词语、动作和完整分支仍按各自层级选标点。
- **在改变条件的位置补解释。** 对象已选定时，让它继续作主语；新条件改变了前述过程，就在此处交代后果。关系连续时可句内展开，完成一项认识、命名现象或转入新任务时也可独立成句。
- **让前段所得在后段发挥作用。** 回指一个概念后，使它成为条件、比较对象或待解释的问题。只重复名词或宣布已经明白，尚未增加这段联系。
- **例后处理真正留下的问题。** 例子已经完成区分，可以结束或继续新问题；读者还不清楚为何重要，就接着解释这层用途。统计中冒号、破折号集中时，优先查是否反复引题或重复总结，而非机械替换符号。

## 4. 用真实试写检验采用

按[校准流程](benchmarks.md#6-运行与修订)保留材料、原稿、实际反馈、修订与后续题。先写有明确事实和读者前提的局部文本，文字首判只依据稿面；专业含义另核。统计帮助定位，是否改进由具体前后句和读者能否复原关系判断。

同题修订用于解决已发现的问题；再换材料观察能否迁移。已见题、共享账号记忆、额外提示和方法版本变化分别记录，不把重复同题称为未见测试。作者宣称自然或模型评分提高不能代替实际审读，更不能代替用户的读感。问题已得到具体处置后交付，不为追求样文数字而继续改写。
