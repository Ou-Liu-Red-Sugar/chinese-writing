# 中文写作校准

这套校准用于发现和修复具体写作问题，适用教材、说明、研究报告与参考记录。它分别保存流程、文本、读者任务和用户认可的证据；任何一项都不自动证明其他三项。题库是封闭材料的合成练习，涉及融资、概率和经营数字的题目不构成真实公司研究。

## 1. 材料身份与用途

[公开题库](../assets/benchmark-cases.json)共有 18 题、54 道理解题。`training_seen` 表示沿用了用户已经示范的融资关系或句序问题；`public_diagnostic` 表示公开诊断题，新编身份不等于对执行者未暴露。这两个名称记录材料暴露，均不等于未见测试。执行者读过全题库、参考答案或历史示范后，不得把同题成绩称为独立泛化证据。新编的不同题也应记录是否接触，不能仅凭文件名叫它留出集。

题目分为 `writer_packet` 与 `reviewer_key`。调度者只能把前者交给作者，不发送完整 JSON；作者须有材料、前后文、先修和任务约束，但不取得必保语义清单、理解题答案与诊断提示。文字审读首判只取得稿件、读者先修、题目与使用场景、实际前后文，不取得原始资料、作者意图、旧结论或 `reviewer_key`。专业审查在具体内容具备后可取得两部分，核本轮实际采用的语义、数据和计算。文字首判保存后，才按疑点取得专业意见或判别依据；最终由文字角色定稿。角色、成熟度与精度权限统一沿[专项检查](specialist-checks.md#2-后续版本的专项检查)。

读者测试另行提供成稿、读者先修及从 `reviewer_key.comprehension_questions` 抽出的题干，不给材料原件、答案、评分和作者解释。若需要查证来源，另记为材料核验，不与只读成稿的测试混记。

既有用户示范保持原文及评价身份，不追打分，不把助手对示范的解释记作用户认可。可用它们分析缺少的关系、句序和承接，并观察新题是否仍出现同类问题。本题库中的融资题是重新构造的数据练习，不是对用户原文的评分。

默认表达偏好见 [写作原则](../docs/style-guide.md)，局部组句示范见 [校准材料](../assets/sentence-calibration.md)。方法形成期间的内部试写及旧分数不作为公开成绩；本仓库只发布可取得的题目、解释及实际示例，不补造历史原稿或评审。

## 2. 按用途检查

| 模式 | 读者需要完成的事情 | 应有证据 |
|---|---|---|
| `teaching` 教材 | 解释关系，完成计算或迁移 | 定义和推导完整；读者能回答对应问题，并指出正文依据 |
| `explanation` 说明 | 理解对象、区别、过程或操作 | 主体、先后、条件、范围清楚；读者能复原指定过程 |
| `report` 报告 | 使用判断，复原依据及成立条件 | 数字和证据身份稳定；读者能分清结论、假设、未知及其影响 |
| `reference` 参考记录 | 准确查询和复核 | 字段、术语、单位、期间、版本、来源一致，定位方便 |

报告不强求教学练习，也不为了评测增加 Bull / Base / Bear / Tail 或估值。研究项目确有相应内容要求时，内容审查沿项目规定执行。参考记录允许并列对象按名称或查询习惯排列；可互换的平行栏目不是结构失败。混合文章分别说明主用途和附件职责，不能用原表齐全证明教学关系已经讲清。

## 3. 四类证据与流程检查

| 证据 | 检查对象 | 能支持的结论 |
|---|---|---|
| 流程遵守 | 题目要求的实际过程：完整写作核草图、审读、修订与填充；局部编辑核原稿、改稿及改动理由 | 是否按本题范围完成工作 |
| 文本质量 | 定位到句、段、公式或字段的问题和理由 | 该文本的正确性、清楚程度及编辑问题 |
| 读者任务表现 | 只读成稿后的答案、正文依据、错因及测试条件 | 该执行者在该任务中的理解和查询表现 |
| 用户认可 | 用户原话、时间、指向的版本与认可范围 | 用户实际接受了哪些文字或原则 |

按各题 `required_artifacts` 确定流程检查范围。完整写作无法取得要求的过程材料时登记流程未证实；若已知一次生成全文后直接复制为正文、没有实际草图审读及处置，则判流程失败。局部编辑只要求实际原稿、改稿与理由时，不另造第0版、第1版或全文草图，也不因未经历这些阶段判失败。不能从最终文字反推已经走过流程。文字通顺不能覆盖错算，工具校验通过不能覆盖语义缺失，模型读者答对不能登记为真人教学效果。用户尚未评论时填写“未取得”，不能把沉默写为接受。

完整写作的分阶段检查沿 [workflow 第2–4节](workflow.md#2-第0版与第1版草图)：第0版可用图表，只核思想及如何体现；第1版核每段大致内容、真实衔接句、标点及其间内容安排，中间句子未展开不判失败。遇到从观察转向行动、从期待转向实际结果等关键转接，要读出前句提供了什么、后句接着谈什么，以及中间所需的解释是否已写定；一个关联词或“此处补过渡”的占位不能替代这项工作。后续版本核对第1版的实际修订。最终验收才要求骨架完全确定、局部内容可直接填入。时间戳、状态字段和文件名不能替代工作；固定文字对照只检验已写定部分，另核所安排内容是否落实。不得倒拆全文或复制版本凑过程，不固定修改轮数。

要求第0版时，按[全篇起承转合](composition.md#第0版的起承转合)核思想和阅读进程，追踪各处承接、转进与回收的依据，将详略、节奏和语气一起判断。六项回答与知识点齐全、画出四个标签，都不足以证明文气安排成立；原材料目录换成流程图也不自动成为全篇组织。

完整写作另核[取材与深挖](workflow.md#取材与深挖)的深度和时点：早期检索是否只服务草图，是否已逐表取数、校口径、追长引用或完成系统计算；第1版交出后是否才进入深挖。看到数字不自动判违规，也不能因每次读取很短就忽略实际已经做完的一轮深查。记录作者收到的素材与数据暴露；已经读过完整旧稿或大量资料的会话，不能当作仅经浅层取材的新实验。局部编辑和封闭材料练习按实际输入记录，不补造没有发生的资料阶段。

要求第1版时，先核[阶段接收](workflow.md#阶段接收检查)：实际中间说明、算例和解析已经写成全文，即使状态为待审或把答案括作占位，也不满足本阶段。准确记为提前形成的初稿，不由文件名追认；不用字数或空缺比例代替判断。再核[具体方法](specialist-checks.md#1-第1版生成时使用的方法)如何将第0版的全篇安排落实为实际段落、句群和标点，后续反馈与处置能否定位。未填数字和专业细节保持待核，不据此判早期骨架失败或冒记专业通过。

最后核文字角色是否在专业意见处置后完成定稿，以及实际成稿是否经过它的收尾；专业角色的末轮直接改写不满足该要求。局部编辑沿实际句群核相应方法和改动，不补无关篇章阶段。早期文气安排、实际句段质量与成稿效果分别按各自已完成的职责判断。

## 4. 五项门槛

采用五类问题作为诊断入口。每项记 `pass`、`fail` 或有理由的 `not_applicable`，同时给位置和语义解释。重大失败先回到相应草图环节；可以同时修复相关句法，不机械禁止一切逐句修改。

| 门槛 | 判断依据 | 不足以单独判失败的表面信号 |
|---|---|---|
| G1 对象与文体 | 正文是否完成读者任务；条件是否贴近命题；后台流程、自我减责是否挤占内容 | “注意”“可能”的次数；某个否定词是否出现 |
| G2 方向 | 当前段落对任务承担什么作用；连续解释能否追踪；参考记录能否定位待查项目 | 没有显式“中心问题”；未在固定百分比处设置路标 |
| G3 完整 | 是否缺少影响理解、计算或采用的关系、步骤、条件与证据身份 | 篇幅短；未讲解读者已经掌握的基础 |
| G4 题文 | 有标题时，标题是否准确覆盖本文对象和范围；无标题且任务无需标题时可不适用 | 标题形式普通；与别的文章存在相同词语 |
| G5 结构 | 从句群到篇章的连续解释是否成立；后一判断或动作所需的对象、理由、条件是否已由前文或读者先修提供；平行分支内部是否连续、同层字段是否可比较 | 出现或未出现某个关联词；平行分支可以互换；段落长度相似；正文没有 H2 |

随机换序只可用来发现连续论证可能没有推进，必须指出具体关系才能形成结论。句间衔接也按连续片段判断：指出哪一句开始要求读者自行补出哪一步，或在哪一句把材料中的先后、并列误写为因果。参考记录字段换序仍可查询，通常是正常结构。标题可替换、段长、词频和禁用词扫描只作定位线索；用户明确的词面约束仍要执行，但不能把消除词面命中宣称为文本质量已经合格。

## 5. 十项诊断分

采用10项、每项0–4分的诊断尺度。4 表示该维度在本题任务中充分成立；3 表示存在局部编辑问题；2 表示需要实质修改；1 表示明显妨碍任务；0 表示缺失或误导。每一分附证据位置和理由，分数不制造小数精度。判断不适用时写 `null` 及原因，不为了凑 40 分制造标题、教学结尾或额外章节。

| 项目 | 要检查的实际关系 |
|---|---|
| R1 标题 | 对象、范围与内容相符；不以套用程度直接判定 |
| R2 路线 | 段落或章节组织符合解释依赖、操作步骤或查询结构；无须强设小标题 |
| R3 中心 | 材料围绕任务选择；参考记录可围绕明确查询范围 |
| R4 段落 | 连续语义单元完整；不以段长统一或一段一句为目标 |
| R5 句子组成 | 沿句群核主要动作、承担者、主体转换、谓语搭配、指代、词序和修饰范围，再核分句组织、句界与标点；已知承担者是否便于辨认，前置话题是否遮住主干，连接词后逗号是否确有分句或插说边界；不能以每个短句各自正确代替整段自然 |
| R6 推进 | 在实际连续片段中追踪已知对象如何带出新信息、后一问题或动作从前句何处接出；检查必要解释及实际转折是否成立，同段内等价句的次序是否回应后文；既查漏接，也查无依据的强接 |
| R7 关系完整 | 本题必要的机制、定义、推导、计算或字段关系齐全 |
| R8 详略 | 难点得到展开；先修、旁支、过程和重复提醒只留必要部分 |
| R9 限定 | 删除防御性表态，保留影响命题真值、来源身份、条件与行动含义的文字 |
| R10 完成 | 读者任务得到满足，最后一个有效内容后结束；不要求加总结或迁移练习 |

R5 的理由应区分语义或语法错误、增加阅读负担的安排，以及默认表达偏好的选择。已知动作优先让读者直接读出谁做什么，但结果作为话题、承担者未知或原文引述时，被动句可能正合需要；同一承担者的连续动作也可自然省略主语。普通连接词后不自动加逗号，分句和插说的真实边界则按整句保留或重组。不能以删除被字、补齐所有主语或清空连接词后的逗号作为通过标准，更不能改动要求原样保留的引语。每项调整都要回看主体、条件、范围与原有事实是否保持。

R6 的证据至少应能定位一个实际待判断的句群并说明其关系；没有问题时可以直接说明该题关键转接为何成立，无须制造缺陷。核前句使读者等待的解释是否由后句接住，转向比较时维度是否一致。仅有“用了但是”“逻辑清楚”或关系标签，不能支持判断。R7 核必要内容是否齐全，R6 核这些内容怎样在行文中接起来；同一缺口影响两项时共用问题记录，不重复制造问题。连接词还须放进语气和阅读节奏中判断：既检查漏接或生硬，也检查重复提示和推进受阻；关系能由上下文推知不构成删词要求，修改可以增、留、换、删。材料缺少依据时，不能为追求流畅而虚构原因。R8同时核重点是否落实为解释的展开、例子是否完成所在位置的任务，不能只凭标题醒目或段落更长判定。

十项均适用时可记总分 `/40`。出现不适用项时报告适用项得分与满分，不换算成 40 分，不跨文体直接排名。实际读者任务另计，不折入这 10 项，也不靠高总分抵消门槛失败。

十项诊断分用于定位改动，当前没有经过统计验证的总分通过阈值，不设自动Gold或发布分档。即使十项都适用，高总分也不能覆盖具体内容错误、流程缺失或用户尚未认可的事实。

## 6. 运行与修订

1. 选题并登记版本、模式、用途、材料暴露、参与者和预算。只将 `writer_packet` 发给作者。
2. 按题目产物要求执行：完整写作先保存第0版，再形成第1版段落与标点骨架，由实际执行者按该版成熟度审读；保存反馈、处置和骨架修订，Lead核对最终版后才另行下达正文任务。局部编辑保留原稿，提交改稿和实际改动理由，不构造未发生的草图历史。不以早期草图的正文完成比例或固定轮数评分。
3. 文字角色先只依据实际稿件和读者前提作首判，定位入口、句段推进与解释缺口；专业角色在内容具备后另核必保语义、事实和计算。适用的五项门槛与十项诊断按本轮职责给出证据，未具备的内容留待后续，不因评分表存在就提前核算或填满骨架。修订后连续读受影响句群，不能凭多了关联词、改成主动句或少了逗号结案。
4. 有条件时安排独立读者。记录其是否为模型、读过哪些材料、是否看过答案、实际问题与回答。作者自测登记为自查。
5. 将问题定位到最早受影响阶段，按具体理由修改，专业意见处理后由文字角色决定最终详略和表达精度。填充及必要核对完成后仍由文字角色最后通读；读者测试发现的问题同样交回相应阶段，最后回到文字收尾。理解题答错时检查正文是否允许恢复正确答案，不能只登记错题数。预算不足时交代未完成测试，不补造完成记录。
6. 使用 [报告模板](../assets/benchmark-report.md) 登记四类证据和用户反馈。达到本次完成条件后停止；分数提高本身不触发继续改写。

按待修问题选题：`CW-02` 观察后文导致的句序变化，`CW-06` 观察定义推导，`CW-09` 观察防御性删改，`CW-10` 观察参考结构。针对句间承接，可用 `CW-11` 检查期待、实际结果和改变办法之间的解释，用 `CW-12` 检查话题承接及检查怎样落实为修改，再用 `CW-13` 检查是否把时间先后或并行变化强接成因果。后者防止把“增加解释”执行成“替材料编造解释”。针对局部句法，可用 `CW-14` 检查已知承担者、长话题、主体转换及未知承担者的结果表达，用 `CW-15` 检查普通连接词、插说、条件分句与引语各自的逗号依据。不要求每次全跑，正式数量与预算由当前任务决定。

开篇能力用`CW-16`观察能否从标题和材料建立独立入口，`CW-17`观察前文已建立用途时能否直接接题，`CW-18`观察报告能否回应读者已有的采用任务。只给作者writer_packet及正常skill调用，不在调度消息中复述应采用的开法。文字首判只读标题、先修、实际前文、改后开头和固定后文；先保存它对题意、阅读需要与接续的判断，再取得原稿或判别依据比较。局部练习只支持相应局部能力；完整新写仍需检查第0版的入口选择如何落实到第1版及正文，不能用这类题目替代整篇试写。

审读以题中关系和实际读者任务为准，不要求复现某个标准句、关联词、句数或字数，也不设主动句或逗号数量配额。新增句间题与句法题均为公开诊断材料；已读全题库的构建者可做材料与格式核验，不能担任未暴露作者或读者。短题可以支持实际的局部改稿与读者测试，不能据此声称完整文章流程已经通过。新增题目不表示已经完成作者生成、读者测试或用户验收。
