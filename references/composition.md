# 中文文章的组织与编写

本文件说明怎样选择材料、安排主次和次序，使读者逐步建立本篇需要的认识。阶段定义沿 [workflow](workflow.md)：第0版安排思想及体现方式，第1版落实为段落、真实衔接句与标点骨架，后续据 [专项检查](specialist-checks.md) 修订，验收后才局部填充。句群、主干及标点的具体方法见 [句子组成](sentence-construction.md)，必要条件与防御性措辞见 [限定与删冗](qualification.md)。

文献及采用范围见 [literature](literature.md)。W1、W2提供材料、视点、组织和修改的依据；将组织决定提前完成于最终草图，是用户确定的U2工作方法，不声称原书规定了这套流程。

## 1. 用途、读者与认识目标

先确定文章要使哪位读者理解什么、辨别什么或完成什么，再判断他已经掌握哪些对象、概念和前提。学习笔记安排作者与读者共同观察、比较和取得认识的进程；教材展开初学者尚未掌握的定义、例子与推导；报告把篇幅用于本次事实、解释和判断；参考记录使人能准确查询。第0版同时选定讲述立场，具体沿[作者引导](sentence-construction.md#6-教材语气与作者引导)；任务给出的读者水平与声音优先于默认文体。

写作须有可以落实的内容。标题本身规定全篇主线；第0版先将题意落实为本篇要解释的对象与关系、要回答的问题，再沿它安排材料和起承转合。标题不能替代具体内容，但也不能被放成稿外的标签。材料不足时先补材料或缩小主张；题目由用户固定时，先说明内容缺口，不私自换题掩盖。开头怎样承接标题并点题，正文怎样持续推进和扣题，结尾怎样完成题意，都属于第0版的组织。具体开篇选择见[从标题组织开头](openings.md)。

组织时考虑读者将依次看见什么：当前对象怎样进入，哪些信息使他能够理解，随后还有哪个问题需要说明。前文说要比较两种方法，后面就应保持可比的条件；前文提出一个异常结果，后面就应解释它或说明现有材料能够解释到哪里。这些期待来自实际内容，不必把每段都写成设问或悬念。

### 第0版的检查问题

第0版形成时，在思想图、表格或已有记录中回答以下问题，Lead据具体安排决定能否进入第1版。回答落到本篇的对象、材料和认识关系，不能只填“引起兴趣”“承上启下”“机制讲清”。此时不要求段落、实际衔接句、精确数值或计算结果。

| 检查问题 | 第0版应给出的具体安排 |
|---|---|
| 标题规定什么主线，读者为什么需要学这一篇？ | 把题意落实为要解释的对象与关系、要回答的问题；指出读者需要弄清什么及本篇能推进哪一步，不能只列知识点 |
| 读者从哪里进入？ | 选择能使上述学习理由显现的情境、观察、区别或问题，说明它为何值得这类读者继续看；已有实际前文提供的动机可以直接承接 |
| 为什么选这些材料？ | 案例、数据、图表各帮助看清什么，为什么在此引入；不用“真实”“典型”替代具体作用 |
| 哪里需要充分展开？ | 最难理解的关系或过程，准备用什么解释、例子、对照或推导展开；次要内容怎样取舍 |
| 全篇的起承转合怎样贯通？ | 起处怎样引出需要，承接怎样层层推进，转进凭什么发生，末尾怎样合拢前面的认识；将详略、节奏和语气放在同一安排中，不能只列内容顺序 |
| 本篇在哪里完成？ | 哪些关系在这里讲清，哪些交给后文及怎样交接；检查有无提前依赖后文才会解释的概念，无后文时明确本篇完成边界 |

开头用途不明、案例没有作用、难点缺少呈现办法或认识次序倒置时，先修改第0版。内容与数字未填、段落未写，不构成本版失败。基本概念可在[取材](workflow.md#取材与深挖)范围澄清；需逐项证据或计算才能确认的关系留待深挖，不假定资料必会支持。问题和回答可以嵌在现有草图中，不要求另造检查表。

这些回答是作者的安排。第1版之后，文字审读者先依据实际稿件回答相应问题，首判不取得作者的预设答案；随后再对照计划与文字的差距。不能用第0版答得完整来证明开头与承接已经写好。

## 2. 选材与详略

详略分配读者的注意力。最慢、最详细的部分应落在读者最难跨越、又最影响中心问题的那一步。W1第14–15讲讨论材料选择和叙述快慢；W2第3–4、10、18章把实际需要、材料归并、具体印象和中心联系起来。材料在资料中显眼或便于查证，不足以决定它在文章中占据多少篇幅。

第0版就形成全篇的详略分布，放进思想图、表格或已有记录。先找出中心解释和读者困难，再为各项思想与材料作以下安排：

- **展开到哪一步。** 具体指出要让读者看清哪些中间关系、比较或操作，在哪里完成；背景保留到足以接入重点的位置。只写“详写机制”“充分解释”没有确定深度。
- **怎样展开。** 选择连续说明、一个完整例子、两种经过的对照、推导或图表，并说明它承担的作用。迁移例只改变关键条件时，不必再重复整个主例。
- **相对份量与节奏。** 决定哪一部分占主要篇幅，哪里放慢，哪些内容简要带过；必要时给大致篇幅区间或相对比重，供全篇取舍。预计篇幅服务于组织，不是强制字数、段长或验收比例；还未写段落时不必提前逐段定长。
- **材料与精度的去向。** 确定本篇需要哪层概念、哪些数字及什么显示精度，哪些原表、术语分支、来源细节只供核查或留给后文。这里决定呈现需要，不提前核算未填数据，也不因来源精细就全量搬入正文。

完成后把各部分放在一起比较：主要篇幅是否给了中心难点；背景、材料辨认或口径说明是否挤占了本篇要教的过程；多个“详写”项目是否真的有同等必要性。逐行贴详写、略写标签不能代替这项全篇判断。某项背景本身需要长篇讲解才能使用时，考虑换更易进入的材料、缩小本篇用途或给它独立位置，不能把必要理解留给读者猜。

第1版依这份分布安排章节、段落和标点：详写部分有明确的中间内容与呈现位置，略写部分保留实际衔接；此时仍按阶段要求保留语义占位，不用提前写完正文证明篇幅安排。后续发现必要解释被低估，就连同其他部分重调分布，不能只追加新段。文字角色定稿时据实际阅读效果决定最后详略和显示精度。

**自拟例：重试请求。** 初学教材的重点可放在两种经过的对照：请求尚未处理就中断，以及请求已经处理但响应丢失。第0版安排各自的动作与后果完整呈现，使重复执行的问题有来路；网络协议背景只交代读懂这两种经过所需的对象。面向已熟悉重试机制的报告，则把主要篇幅给本次故障位置、证据和影响。同一材料的详略因理解任务而变。

例子先有职责，再定位置。引入问题的例子使问题可见，解释定义的例子使区别可辨，展示操作或推导的例子完成关键步骤，检验边界的例子指出改变的条件。同一例子可以连续承担相关职责，但转换要清楚。事实性文章从材料取得细节和因果，不为讲得顺而补造事实。

例子自身也须有能理解的情境：当事人面对什么事情，动作怎样接续，某项条件为何影响当前问题。真实材料保留与理解有关的经过；假设例子可以简化，但不能为了覆盖多个检查点而拼接数字、日期和例外。解释设定本身若比目标概念更费力，就缩小这次例子的职责或重新选材；用户固定的题设先指出具体问题，不擅自更换。故事生硬时回到材料和情境，语句通顺、算术正确都不能替代这项判断。陌生例子的额外理解成本计入详略安排。

## 3. 全篇次序

第0版要把全篇文气一并安排。本方法将文气落实为可以检查的组织：同一中心之下，意思怎样接续、推进和回收，读者的疑问怎样引出后文，叙述在哪里放慢或加快，以及语气如何保持一致而有变化。文章可以逻辑无误却一路平铺，也可能开头有吸引力、进入主体后便失去方向；第0版须从进入直到收束统筹这条进程。

这项安排综合采用W2第27章的秩序、联络与统一，第21章语调须与前后意思配合的分析，以及W1关于材料取舍、叙述快慢、顺序与读者参与的办法。“文气”在这里是项目的综合操作用语，起承转合也是全篇作用的安排，不声称原书规定了我们的草图阶段。

### 第0版的起承转合

| 作用 | 第0版需要确定的具体关系 |
|---|---|
| 起 | 怎样承接标题、点明本篇主线，从什么可理解且值得关注的事情进入；使读者开始关心哪一个问题，并准备沿什么方向追下去 |
| 承 | 接住起处引出的对象与疑问，用哪些观察、解释或例子把它推进；每一层新增什么，使下一层有继续展开的必要 |
| 转 | 前面怎样形成转进的需要，用什么有据的区别、新材料、视角或任务变化将认识带到下一步；转后仍怎样服务同一中心 |
| 合 | 前面的哪些认识在这里汇合，读者现在能够回答或完成什么；怎样完成题目与起处提出的任务，在相应问题得到处理的位置结束 |

四种作用不等于四段、四节或四个等长部分。承接可以分层，转进可以多次；转也可以是从现象进入解释、从例子进入一般关系或从认识进入使用，无须制造反转。合应当接住前面实际建立的内容，不能临末另加一个新主题或模板总结。

将这些作用落到本篇具体思想、材料和读者认识的变化上。可用流程图、表格或连续说明；图的节点标明这一步让读者看见什么，连线说明为什么由此走向下一步；表格同样写清承接、推进与转进依据。只画“起—承—转—合”、贴“承上启下”标签或按资料名称连箭头，尚未完成设计。

把详略、节奏与语气放在同一安排中：哪里要让读者停留，具体看清一个过程；哪里只需简要经过；哪个转进值得充分准备；哪里开始回收、收束。还要定下适合本文的叙述姿态，例如共同辨认现象、耐心推演关系或直接说明判断；转入新材料不应无故变成审计清单、反复告诫或另起一篇介绍。第0版规划这些变化，第1版再落实为段落、句群、真实衔接和标点，此时不提前写完整正文或逐句安排音节。

Lead从头走到尾核这份安排：上一项留下的对象、疑问与期待，下一项究竟接住了什么；每次转进的来由是否已经形成；主例、旁支和补充能否返回主线；末尾完成的是否就是开头值得追问的事情。主题相同和知识点齐全不足以证明文气贯通，有一处须靠作者临时补讲才连得上，就在第0版修正。

### 开头、展开与收束

按[开篇方法](openings.md)接住标题、选择读者能够进入的具体关系，并在实际文字中点题。学习理由和兴趣来自这项关系在当前读者认识中的作用，作者的任务说明不能代答；已有前文建立需要时直接承接。开头引起什么期待，主体就安排相应解释、比较或发现，并让每次转进仍然服务标题规定的主线。

主体的次序依理解需要选择。报告可以先给判断再说明依据，教材可以从对象或问题起步，也可以在前提具备时直接给定义。比较可行次序时，核哪一种使当前关系容易辨认，哪一种让读者暂记过多未解释的东西。并列对象保持共同比较维度；转变对象、时间或观察范围时安排实际联系，不靠增加连接词掩盖材料断裂。

收束依前文建立的认识完成该篇任务，可以回答最初的问题、形成可使用的判断或交出下一步所需的产物。真正需要的综合能使前面内容共同发挥作用；事情已经说完时就结束。详略沿第2节、具体段落与句群沿后续各节落实，全篇文气与局部表达共同核看。

## 4. 章、节与段落

章或节承载可以分别识别的内容任务，段落承载一次连续的说明、论证或叙述。第0版的一项思想可以分成几段，几项相关思想也可以合成一段；标题便于定位，换段表示内容变化，不按材料篇数或知识名词机械分割。

组织一段时，先确定它承接哪个已知对象、要让读者看清什么、到哪一步完成。主要内容要有足够展开，解释、例证和背景的位置应帮助它成立。读者需要先知道主要对象时，尽早交代；次要材料若打断主要关系，就调整位置或另行展开。同一过程尚未说完，优先保持连续；对象、时间阶段或论证作用变了，再决定是否换段，长度本身不决定分合。

段末留下的信息会影响下一段从哪里开始。第1版须写出实际起句或衔接句，中间内容可以暂留明确占位，但所需解释及其前后作用已有安排。连读“本段末句＋下一段首句”，核后文使用的对象、原因和条件是否已经进入；不能只看旁注中的段落职责。

**自拟例：从发送到重试。** 上一段说明发送请求，下一段要解释重试，可以先写：“客户端等到超时，仍没有收到响应。”读者据此进入重试问题。只把“因此”放在发送与重试之间，没有交代客户端遇到了什么；有关第一次请求实际状态的判断，还须由材料支持。

连接词与句序、共同话题、回指和对举一起组织行文，按语义、语气和阅读节奏选择。即使读者能够推知关系，也可以用适当连接使转折、递进、承接或归结更自然；不能把“不加也能懂”当成省略的充分理由。连读时同时检查衔接不足和机械提示，具体取舍沿 [句子组成](sentence-construction.md#2-按关系组合分句)。增加连接词不能代替重排材料和补足解释，删连接词也不能成为精简目标。

路标句可以帮助读者进入较长推导、切换观察范围或开始比较，须实际写入骨架。它之后仍要有对应内容；段落已经自行推进时，删去重复播报写作安排的句子。承担回指、转向和推论依据的文字，即使不增加独立事实，也可能是必要的。

## 5. 组句与成稿声音

篇章安排要进一步落实为句群。按 [句子组成](sentence-construction.md)，先确定本段的表达动作及句间关系，再安排主干、共同成分、词序和标点；不是先写一串孤立短句，再用关联词串起来。公式、表格和引文同样参加说明，前面写定引入什么，后面接住已得到的内容。

主次也体现在句内。有时应使重要对象先出现，有时应避免次要说明打断主要谓语；直接动作、被动、话题前置、长句或短句分别依当前焦点选择。技术术语和变量保持一致，译写时保留准确关系并重新组织中文句法，不为词汇变化更名，也不逐项照搬外语结构。

成稿声音由取材、措辞、句式和阅读进程共同形成。学习笔记和带读型教材沿[作者引导](sentence-construction.md#6-教材语气与作者引导)把共同观察与推理写成实际句群；报告可以直接给判断和理由，文学作品按任务要求保持其声音。有效的重复可以使比较对应或使讲述关系持续，不必为了变化而改写。风格评价落到作品中的实际选择，核读者如何跟上解释，不只用“自然”“雄健”“简洁”等形容词下结论。

必要条件和证据身份按 [限定与删冗](qualification.md) 放入对应命题。它们确定内容的成立范围；反复自我评价、泛化强调和无功能谨慎尾句不参与说明，应当删去。

## 6. 草图连读与完成

连读当前骨架，看读者依次得到了什么，哪些内容成为了理解重心，哪里产生了需要解释或比较的问题，后文是否已把它解决。主次、详略和次序应体现在材料及实际文字中；“重点突出”“此处承上启下”不能替代安排。能自然承接的地方保持原样，只修实际障碍。

第1版暂不展开中间说明，用具体语义占位配合实际起句、承接和标点来确定组织。Lead先按[阶段接收检查](workflow.md#阶段接收检查)核其形态，不能把全文成稿直接作为首次骨架送审。后续依实际反馈修订关系并写实承重解释，使最终草图中的材料取舍、段落、句序、衔接、例子、公式、条件与标点都已确定。剩余文字只表达已确定的局部内容，填充者不再设计论证、移动例子或选择如何接续。真实反馈、冻结及发现错误后的退回规则统一见 [workflow 第3–4节](workflow.md#3-草图修改与最终验收)。
