# 草图中的句子组成

本模块用于第1版的生成和后续句法专项。输入是前文已建立的对象、当前段落要完成的解释、已核材料及后文去向；产物是已经写定起句、关联词、句内层次、句界和公式引入口的骨架。中间事实或推导仍可用明确占位表示，起承转合不能只留在旁边的职责说明中。

文献依据见 [literature](literature.md) 的G1–G10、D1及N1，用户示范与改句对照见 [校准材料](../assets/sentence-calibration.md)。下列组句办法结合原文分析与用户偏好，不把文献分类或个人文风当成适用于所有语境的句式模板。

## 1. 先安排句群承担的动作

从前文进入本段时，先确定读者已经知道什么，这一段还要使他明白什么，再安排必要的设定、观察、比较与解释。继续同一对象、转入新对象、从例子推广、增加条件和给出推论，各有不同的起点。句群可以由一个复句或几个句子组成，不先按每个事实分成独立陈述。

让重要对象及时出现，随后围绕当前问题展开。前句说“这一步容易出错”，后句就须指出错在何处；前句提出两种办法的比较，后句应保持相同的比较维度。读者需要转换对象、时间或观察立场时，在转换处交代。详略和材料位置沿 [篇章编排](composition.md) 确定，这里把这些安排写成真实句群。

连读前后句，具体找出：前一句已经交代了哪个对象、判断或动作，后一句接着它增加什么，读者凭哪些已经给出的信息能够走到这一步。同一话题、相邻位置和时间先后都不能单独证明解释已经接上。尤其在期待落空、改变方法、引入新对象、从检查转入修改或从设定进入推论时，要核是否省掉了一项读者需要知道的理由、条件或动作。

缺少的内容先回材料中找。材料已给出且当前读者需要的，就在草图中安排它怎样进入；材料未说明的事实、动机或因果，不能为了连贯而补造。此时可调整主张、保留并列或先后关系，或把确需查证的问题记回材料阶段。读者已经掌握的常识和前文已经建立的依据可以直接承接，不把每一步都扩写成解释。

第1版写出起句、必要过渡和承接对象；中间专业内容可以占位，但占位要说明已确定的哪项内容，以及它怎样供后句使用。引入这层内容的句式和接向后句的实际文字也应进入骨架，不能只在旁注中说明关系。具体示范见 [校准材料](../assets/sentence-calibration.md#只补关联词仍缺一步解释)。后续修订把承重解释写实，最终草图不再留给填充者决定如何接续。

用户所说的起承转合落实为从哪里起、承接什么、在哪里改变范围或方向、到哪里完成当前意思，按本段需要安排。例如“现在，让我们将上述讨论推广到更一般的情况”指明观察范围变化，应当进入骨架；后台的“本段作用：推广”不能替代它。无需给每段或每句套齐四个标记。

## 2. 按关系组合分句

G7〈复合句〉先辨主语的相同与不同，再讨论分句关系；G9〈层次〉进一步通过改句处理层级、次序和从属内容。用于草图时，将连续内容分清设定、补充、解释、因果、条件、比较或推论，再决定哪些共同完成一句话。

同一设定过程可以连续使用“考虑……，并设……，记……”。读者沿着同一个建模动作逐步认识对象和记号，无须把每个设定都拆成独立的“某物是什么”。如果后半句改换行为者或讨论层级，需给出相应主语和连接；关系已经完成或出现另一条需要独立展开的思路，再断句。

关联词在第1版就应确定。需要表示前提的用条件关系，需要提示结果的用结果关系；“则”“因此”所接的内容须有前文依据，新增定义也应让读者知道正在命名或构造。处理衔接时区分三种情形：

| 当前问题 | 在草图中的处理 |
|---|---|
| 关系已有依据，但实际文字没有表达清楚 | 调整句序、句式、回指或关联词。例如先写希望达到的结果，再用“但是”接未达预期的事实，使改变办法有明确起点 |
| 中间缺少读者需要的理由、条件或动作 | 先从材料补足这项内容，安排其进入及后句如何使用，再确定连接。“于是”不能代替为什么这个办法能回应前面问题的说明 |
| 材料不足以成立所写关系 | 降回有依据的并列、时间先后或待判断状态；不使用转折、因果词替文本新增事实或结论 |

“但是”可以表达期待与结果的落差、对前项的限制或方向的转变；“虽然……但是……”组织让步；“于是”把已有理由或情势接到下一步动作。具体选择服从本段关系，不按词表逐项插入。“已有初步安排”转向“这些安排是否合适还需检查”时，两端要谈同一项安排；换成另一个检查项目，不会因有“但是”就自然。

关系确定后，再判断哪里需要关联词。句序、共同话题、回指或对应句式已使接续清楚时，直接往下写；不要每推进一句就加“因此”“同时”“此外”。例如“审读者标出了两处跳步。作者补上推导，把修订稿发回”，动作和交接已经清楚，无须再用“于是”“随后”“最后”逐次提示。这个例子是自拟材料，不规定所有连续动作都省略关联词。

需要改变读者的理解方向时，保留相应提示。例如“推导已经补上，但其中一个前提仍缺依据”，后句限制了前句可能引出的完成判断，“但”有实际作用。条件、让步和推论也按各自关系处理。试删时核读者是否仍能辨清两句的关系及范围；试加时核这个词是否只在播报已有次序，或擅自增加了因果。成对关联词可以帮助划清复杂层次，不能因减少连词而机械拆散。删留依据是当前句群的作用，不设词频配额。

骨架的组织示例（助手自拟，用于演示安排）：

> 前面的例子只用了两个取值，现在将它推广到有限多个取值. 设〔变量及其取值〕，并以〔相应概率〕作为权重，则〔本段要定义或求出的量〕可以写为：

这段已经定好例子到一般设置的转场、两个设定的关联以及公式的引入。占位不能自行增加第三层条件或另改句法；如果当前设定不足，就在骨架阶段补齐。

## 3. 前后句的承接对象

先确定本句谁做什么、陈述什么状态或关系，再选择怎样承接前文。前文已经出现的对象可以放在主语、宾语、状语或回指中；承接旧信息不要求把它放到句首。说明作者怎样改稿时，“我需要逐处修改这些笔记”既接住了笔记，也接住了前文的“我”，通常比“这些笔记需要由我逐处修改”直接，同时保留了必要性的语气。

连读时核对主语、讨论对象和观察范围是否变化。可以重复名称、用代词或省略，选择依据是读者能否跟上实际动作及所指；同一承担者连续做事时不必每个分句重新点名，换了承担者就按需要说明。D1的话题链研究帮助检查对象与回指，不规定旧对象必须充当下一句的主语，也不规定所有句子都由人开头。

在骨架中写出“上述讨论”“这个条件”“由此得到的均值”等词时，指出它们具体回指哪一处。一个指代可能同时落到两个对象上时，恢复名称。叙述在实际结果、观察者已知信息和作者全貌之间切换时，写明观察立场，避免读者刚被告知结果，又被说成结果未知。

方法说明中的动作也要接续。写“检查、处理、完成”时，确定检查什么、会辨认出哪类问题、发现后怎样修改，以及修改结果如何供下一步使用。按本篇需要写足这一段联系，避免列完检查项目就跳到“因此完成”。它可以在复句中展开，也可以借具体例子说明，不强制拆成四个步骤或每段都走一遍。

公式也参加承接。公式前确定正在定义或计算的对象，以及“写为”“得到”“满足”等具体动作；公式后使用已经得到的对象继续解释。不要把完整的设定切成几句后，再让一个孤立公式负责替作者串起关系。

## 4. 主干、词序与共同成分

先找主要谓语，核清是谁在做这件事，或什么对象具有所说的状态与性质，再安排对象、条件和修饰语。叙述有明确承担者的写作、研究或操作过程时，优先让承担者直接完成动作，不惯用“内容需要得到处理”“问题可以由作者解决”等表达推迟主要动词。第1版就要写定这些主干，不能只在旁注里说“主体明确”。

| 句子的实际任务 | 组句选择 |
|---|---|
| 说明已知的人或机构怎样行动 | 优先采用“作者核对数据、补上例子，再修改结论”这类连续动作；前文对象仍可放在宾语位置 |
| 动作转交另一人 | 在交接处点明承担者，如“审读者指出缺口，作者据此补上解释”；不要从“理由无法取得”直接跳到省略主语的“就回查草图” |
| 描述对象的状态、遭遇，或施事未知且无需追查 | 可以保留被动、受事话题或无主句；例如“备份已被删除，日志未记录删除者”。不能为了主动表达编出删除者 |
| 延续某对象或作对比、交代归属 | 按上下文保留话题前置，如“这本书我读过”“本文由 Agent 撰写”；不把所有前置都当成宾语倒装错误 |

主动表达是当前过程说明的默认选择，不是通用于所有汉语句子的语法禁令。也不机械删除“把”字句，或反复添加“我们”“作者”制造新的生硬格式。G1、G2和G8提供主谓配合、省略与共同成分的辨析；共用一个主语时，要检查后面的每个动词仍由它承担。

主干确定后，再按G3、G4安排时间、条件、范围和其他修饰语，使它们贴近所管的内容。避免先堆一串名词或“怎样……”小句，等到句尾才补“需要处理”“尚未确定”。例如在“我们知道要写哪些内容”之后，可接“但还没确定怎样把它们接成段落”，让同一个“我们”连续承担“知道”和“确定”。调整词序要保留原有范围、焦点与证据身份。

主干清楚以后，还要看本句重点。介绍一个新对象时，先让读者认出它，再补履历或条件；承接已有对象并着重报告结果时，不让次要背景隔在对象与结果之间。G9〈层次〉对长修饰语给出了两种不同安排，取舍正取决于当时要突出主语还是谓语。不能把“重要信息及时出现”简化成一律把宾语前置，或一律写成人名起句。

## 5. 句子的分合与长短

将一项完整设定拆成几个短句，有时会使读者反复重新起步；把几个不同层级的说明硬串在一起，又会使句子混杂。先判断各部分是否服务于同一表达动作，再决定分合，不能以长短本身判优劣。

G9〈层次〉中的修改既有拆开混杂长句，也有增加关联成分、重复共同部分来显出关系。用于骨架时，给长句划清主要关系和从属内容；前提很长、迟迟到不了主要判断时，可先完整交代前提，再用明确的回指接主要判断。需要共用成分时核搭配，需要重复时保留能帮助读者把握层次的重复。

遇到多层抽象名词，先尝试直接叙述有据的动作。假定上下文已确认审读者负责找问题、作者负责修改且两项工作均已完成，就可以直接写“审读者已找出稿件的问题，作者也已完成修改”，避免绕成“问题识别和修改工作的完成”。改句须保留原来的分工、情态和完成状态。成熟术语或持续讨论的概念仍可保留：讨论检验程序时，“兼容性确认”可以作为名称；说明操作时，“先检查旧客户端能否按原来的方式使用接口”通常更直接。

删冗按语义贡献判断，不能见同字就删。“需要完成”与“已经完成”、可能与事实、数量与比例、必要与充分条件，都不能在顺句时互换。读者尚未获得的中间内容也不能为求短而省去；确需补足时沿第1节回到材料。G9及第五讲〈烦冗〉〈苟简〉须合起来使用，不把旧例中的某种删法当作通用词表。

插说、括号和长修饰语只能在不打乱主结构时使用。需要说明的一段经过，可以在骨架中改为独立陈述位置；若拆开会丢失前文话题，就连同前后句重新安排，不机械拆短。

## 6. 教材语气与作者引导

作者可以带领读者考虑一个对象、作一项假设、推广已有结果或比较两种情形。“现在，让我们……”“考虑……”“设……”“记……”在完成这些动作时可以自然使用。这些表达是否保留，要结合当前内容和上下文判断，不能按词面列为废话。

区分具有内容的引导和重复播报。例如从特例转入一般情形、先选定一个条件再计算，改变了读者的观察范围或操作；在步骤已明确后反复说“下面我们继续学习”，可能没有新增作用。检查引导句实际带读者做什么，再作删改。

用户示范确定了当前数学讲解可以采用的自然语气，不要求每节都用同一个开头。报告、参考记录和操作说明仍按各自对象与读者选择语气。译写时保留原材料的精确关系，中文句法重新组织；被动句或名词化只按当前话题的作用判断，不见词即删。

## 7. 标点与第1版的交付

先按句子结构确定主干、分句和插说的边界，再安排停顿。不要在写出连接词后自动加逗号。按用户当前文风，普通连接词与后面的内容尽量连读，避免反复出现“但是，……”“所以，……”“于是，……”的节奏；应连同整句选择位置和分合，不能只按词面批量删标点。

| 自拟对照 | 改动依据 |
|---|---|
| “但是，换个题目，同类问题仍会出现。”改为“但是换个题目，同类问题仍会出现。” | 转折词直接引出所接内容；保留题目变化这一条件之后的分句停顿。此处采用用户偏好的连读写法，不把所有“但是，”都判为语法错误 |
| “如果，作者省略了理由，读者就得自行补全。”改为“如果作者省略了理由，读者就得自行补全。” | “如果”与所引导的条件连读，逗号放在完整条件分句之后 |
| “虽然，例子还没填完，但是，作者已经安排好了句序。”改为“虽然例子还没填完，但作者已经安排好了句序。” | 两个关联词各与自己的分句相连，逗号分隔让步与后续判断 |

必要的条件分句、插说、并列分句或独立提示语仍可形成停顿。G5〈句号、逗号〉直接讨论了句首连接词的连读与有需要时的停顿；N1提供逗号的一般职责，没有逐名规定这些连接词。当前偏好是减少无实际作用的停顿，不能写成“中文一律禁止关联词后有逗号”，也不能据此断言此类用法都来自英语。外部引文和用户原话按其原有标点保留。

连续设定可用逗号和关联词组织；复杂的同层分支可用分号；一句主要意思完成后用句号；“写为：”一类表达使公式成为前句期待的后续内容。不要用逗号替代尚未确定的主语或句间关系，也不要仅凭呼吸、字数或英语词序安排标点。

标点还要服从整句的层次与管辖范围：

- 冒号后面的内容应落实它所提示的解释或列举；后文转入另一个意思时，重新确定句界。不能见到“说”“例如”就加冒号。
- 插说和补注结束后，读者须能接回原句。承重解释安排在正文适当位置，次要说明才按作用放进括注；不能靠一串括号掩盖尚未理顺的主线。
- 分号用于需要区分的句内层次，不按前面已有几个逗号来分配；并列短语与并列分句也不能混用一套停顿。
- 问号由整句是否发问决定；引号区分直接引述与转述。引文和括注内外的点号须结合其是否独立成句处理。

具体形式按N1正文及附录核对。旧书帮助分析表达作用，现行标准与项目排版约定决定当前用法；数学符号另依专业含义处理。若标点无法使关系清楚，回到草图重组句子，不能让符号替代缺失的文字。

第1版除段落内容外，还要能直接读到本句谁做什么、怎样接回前文、哪里切换主语、关联词引导哪一段内容，以及实际停顿放在哪里。中间内容可以占位，但主干、关键语序和连接词后的连读或停顿应有安排。不得把“主体明确”“语法自然”“此处承上启下”留作唯一说明。

原有关键句可以按完成程度修订；中间内容仍用明确占位表示。占位的前后连接词和标点应已写入骨架，使填充者只补内容，不重新选择句群组织。

后续沿实际骨架核读者能否接续理解，不能让职责旁注替正文补讲理由。专项反馈、重要保持判断及记录范围统一见 [专项检查](specialist-checks.md#2-后续版本的专项检查)，最终草图的验收与填充边界沿 [workflow](workflow.md#3-草图修改与最终验收)。
