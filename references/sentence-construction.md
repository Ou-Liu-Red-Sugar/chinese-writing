# 草图中的句子组成

本模块用于第1版生成和后续句法专项。输入是前文已建立的对象、解释职责、取材所得的基本认识与资料需求；第1版之后再加入深挖核实的材料。早期按[取材与深挖](workflow.md#取材与深挖)限制深度，以语义占位安排中间事实说明或推导；起句、承接、句界与标点写入实际骨架，不能只留在旁注。

文献依据见 [literature](literature.md) 的G1–G12、D1–D5及N1，用户示范与改句对照见 [校准材料](../assets/sentence-calibration.md)。下列组句办法结合原文分析与用户偏好；常用表达表属于编辑选择，不作为全网词频排行，也不规定所有文体使用同一种口吻。

## 1. 先安排句群承担的动作

从前文进入本段时，先确定读者已经知道什么，这一段还要使他明白什么，再安排必要的设定、观察、比较与解释。继续同一对象、转入新对象、从例子推广、增加条件和给出推论，各有不同的起点。句群可以由一个复句或几个句子组成，不先按每个事实分成独立陈述。

让重要对象及时出现，随后围绕当前问题展开。前句说“这一步容易出错”，后句就须指出错在何处；前句提出两种办法的比较，后句应保持相同的比较维度。读者需要转换对象、时间或观察立场时，在转换处交代。详略和材料位置沿 [篇章编排](composition.md) 确定，这里把这些安排写成真实句群。

连读前后句，具体找出：前一句已经交代了哪个对象、判断或动作，后一句接着它增加什么，读者凭哪些已经给出的信息能够走到这一步。同一话题、相邻位置和时间先后都不能单独证明解释已经接上。尤其在期待落空、改变方法、引入新对象、从检查转入修改或从设定进入推论时，要核是否省掉了一项读者需要知道的理由、条件或动作。

缺少的内容按阶段处理：早期可适度取材以弄清题意与必要概念，超过该深度的资料和关系记待核，不为连贯补造事实、动机或因果；第1版接收后再深入核实。所得资料改变原安排时调整主张和组织。读者已掌握的常识与实际前文建立的依据可以承接，不把每一步扩写成解释。

第1版写出起句、必要过渡和承接对象；中间专业说明用具体语义占位安排，标明内容及其供后句使用的作用，暂不写成连续解释。引入这层内容的句式和接向后句的实际文字进入骨架，不能只在旁注中说明关系。具体示范见 [校准材料](../assets/sentence-calibration.md#只补关联词仍缺一步解释)。后续根据实际反馈修订组织并写实承重解释，最终草图不再留给填充者决定如何接续；最终阶段的写实要求不能提前变成第1版全文任务。

用户所说的起承转合落实为从哪里起、承接什么、在哪里改变范围或方向、到哪里完成当前意思，按本段需要安排。例如“现在，让我们将上述讨论推广到更一般的情况”指明观察范围变化，应当进入骨架；后台的“本段作用：推广”不能替代它。无需给每段或每句套齐四个标记。

## 2. 按关系组合分句

G7〈复合句〉先辨主语的相同与不同，再讨论分句关系；G9〈层次〉通过改句处理层级、次序和从属内容。用于草图时，先分清设定、补充、解释、因果、条件、比较或推论，再选择读者熟悉的说法把它们接起来。教材和说明可以带有自然的讲解语气，正式术语与数学推导仍按各自需要保持精确。

### 常用衔接表达

下面的候选综合常见中文讲解用语、网络教学材料、词典和[语料研究](connective-research.md)，来源与采用范围见D2–D5。它们包含连词、副词和短语，按写作功能统称“衔接表达”。先认出当前句群在做什么，再选择适合的表达；同一段已经用句序或回指接得自然时，可以保持原样。

| 当前表达任务 | 常用候选 | 选用时的着落 |
|---|---|---|
| 概括通常情况 | 一般来说、一般而言、通常、通常情况下 | 标明正在概括典型情形；“一般来说”适合日常讲解，“一般而言”也可保留。具体历史事实直接按其实际身份陈述 |
| 说明反复或倾向 | 常常、经常、往往 | “常常／经常”侧重反复发生，“往往”常用于某类情形下的倾向；频率和概括范围沿已知材料 |
| 引入情境、条件或等待 | 当……时、遇到……时、如果……就、等到……再、只要……就、只有……才 | “当”给出情形或阶段；“如果……就……”适合带读者进入可能遇到的情况；“等到……再……”交代等待条件满足后才继续的动作；“只要”和“只有”分别涉及充分、必要条件 |
| 带入例子或细化内容 | 比如、例如、拿……来说、以……为例、具体来说 | “比如／例如”落到个案，“以……为例”可选定持续展开的对象；“具体来说”后的内容应确实增加细节 |
| 改述与澄清 | 也就是说、就是说、也就是、换句话说 | 通常让已有意思更容易理解；口语中的“就是说”也可接续话题，具体作用按上下文判断 |
| 承接理由、结果或动作 | 因为、所以、因此、这样一来、于是、就、也就 | 理由和后果前后相接；“这样一来”接变化的影响，“于是”适合引出随后的动作，“就”也可自然连接条件与结果 |
| 转折、让步或修正认识 | 不过、但是、只是、虽然……但、即使……也、其实 | 接明期待与结果的落差或前项限制；“其实”引向实际情形，使用时应有需要修正或揭示的认识 |
| 补充、并行与部分展开 | 也、还、并、同时、另外、还有、其中 | 短词同样能完成承接；“其中”从已提到的整体选出部分，“也／还”在原话题上增加内容 |
| 推进讲述或步骤 | 那、那么、然后、先……再、接着、随后、再看 | “那么”可承接前提引出下一步，“然后”既可表示时间先后，也可推进讲述或话题；依实际关系使用 |
| 比较与对应 | 相比之下、反过来看、相应地 | 保持比较维度；转换方向或对应后果要在实际内容中成立 |

这里的“常用”帮助选择熟悉的措辞，没有规定词频次序或每段配额。语料研究表明，新闻、演讲译文和原生口语常见的表达有所不同；同一个词也可以承担语义连接、话题接续或组织讲述的作用。普通讲解可以主动使用这些资源，不必等到句子已经难懂才补。省去后仍能推知关系，也可能损失带读语气和推进节奏；成稿按阅读需要选择，不照搬会话中的停顿填充。

### 从分句关系重组句群

局部改稿先读前后句，按下列次序定位需要修正的地方；阶段性的思想安排已经成立时，直接从当前句群开始，不重开整篇流程。

1. **还原信息与状态。** 确认谁对什么做了什么，这是通常处理、可能情形、尚待执行还是已经发生的结果；保留条件、否定、时间和来源身份。此时先看要表达的内容，不急着挑连接词。
2. **找出后句接住什么。** 前句会让读者继续关心哪一项：为什么、接着怎样、何时能够继续、前面的判断还差什么？核后句是否回应了它，再辨明两句是条件与应对、动作与后果、等待与继续、预期与转折，还是说明与例子。关系可推知却读起来生硬，也属于可修订的问题。
3. **依认识推进安排句序和层级。** 先让读者取得后句要使用的信息，再组织条件句、主句、插说及句界。常规步骤、异常情形和实际观察可以各有位置；同一过程继续往下说，转换层级时再分句。语序已经合理就保留，不能把每次改稿都说成重排。
4. **用句式和小词把关系写足。** 条件及其应对可以写成“如果……就……”，等待条件满足后继续可以写成“等到……再……”，转折、解释与推广则选相应句式。再把“会、就、才、还、已经、再、了”等放回完整结构，辨认它们规定的情态、动作状态、时间参照、范围或预期；这些作用可能发生在句内，不限于连接两个分句。需要它们时就补入，连同动词形式和对象一起调整。
5. **比较完整表达与省略表达，再连读。** 临时去掉或恢复一两个字，比较读者得到的动作状态、观察时点、条件、预期和承接语气是否相同，不能只问大意能否猜到。再核主语和对象是否跟得上、后一动作怎样接住前一状态、分句的重心与停顿是否清楚。关系已有而表达不足，就补表达；缺少承重内容，就先补有依据的内容；材料不支持的因果和频率仍不添加。给出修订后的实际句群，使方法能落到文字。

这一检查结合G10〈苟简〉、G9〈层次〉与G11〈虚字〉：分别诊断词语或中间内容欠缺、分句关系未展开，以及小词对整句用法的影响。句法完整、事实可辨、读者能顺畅取得全部意思，应当分别核看。旧教材中的个别绝对用法判断按适用范围处理，不能直接变成现代禁词规则。

用户的上传示范让这些动作可以具体核看。原稿已给出断网、停止和恢复后的继续，关系基本可推知；修订将读者带入情形，并写出前后动作的依赖。后来的完整示范又补足了顺序、通常行为及完成状态：

| 示范中的文字 | 让读者取得的信息及后文怎样接住 |
|---|---|
| “程序首先会将文件保存在本地” | “首先”安排流程起点，“会”说明程序的一般处理；“将文件保存在本地”让对象与处理结果完整出现 |
| “如果网络断开，就不会上传” | 先给情形，再用“就”接相应处理；“不会上传”把该情形下动作是否发生说清楚 |
| “等到网络恢复后再继续上传” | 回答前面的上传任务何时能继续；“等到”交代等待，“再”与“继续”接回同一任务。恢复条件不被误写为前一动作造成的结果 |
| “测试文件在昨天下午两点就已经上传完成” | 从一般流程转到具体测试结果，把已经完成的状态落到一个参照时点。“就”在这里与完成状态、时间和预期合看，其作用不同于前面条件句中的“就” |

这种修正同时涉及关系、句式、动词和小词。完整示范仍用了“网络断开”，说明自然程度要连同句群判断，不能把“断了”固定评为更好。保持上传这一对象，也有助于读者辨认“继续”接回什么；不为消除字面重复而换称谓。最新示范由用户给定，可按其意图保留。“不会上传”与“暂停正在进行的上传”、“到某时已经完成”与“恰在某时完成”各有不同语义，改写其他材料时须先确认所需意思。原话、局部修订与完整修订的身份见[对应校准](../assets/sentence-calibration.md#六从操作摘要到条件与等待的讲解)。

迁移时按新内容选择关系。合成题设“材料未齐时不开始审核，补齐后开始”，可以写“如果材料还没齐，就先不开始审核，等到材料补齐后再开始”。另一合成题设是“试验失败了，但它暴露了接口问题，因此仍有价值”；其中应接明转折及价值的理由，不能套等待句式。两项题设仅用于说明组句方法，不作为领域事实依据。

### 完整讲解与适度从容

起草时就让关系、语气和节奏一起进入句群。适量的铺垫、呼应、引导和停顿，可以让读者顺着解释走；它们的作用也应计入表达效果，不要求每个词都新增一条事实。例如“我们先看一个例子”可以带入后面的具体讨论，“这样一来”可以让读者在前项变化后接住结果。是否使用仍取决于这一段正在怎样展开。

修改时比较整段读感：如果句子只剩事实并排、动作之间跳得太快，或像提纲一样处处硬省，就恢复读者需要的承接和自然句式；如果连续几个提示重复同一意思、正文迟迟不推进，就合并或删去。先判断完整说法是否顺畅，再决定哪些字可以省，不把最短表达当作默认成稿。

用户用啤酒与泡沫比喻这种分寸，具体校准见[示范记录](../assets/sentence-calibration.md#六从操作摘要到条件与等待的讲解)。方法采用的是扎实内容与适度语气共同服务阅读的要求，不设字数、词频或固定比例。第1版草图就写定相应承接和句界，未展开的中间说明仍保留明确占位；停顿按第7节处理。

数学骨架也可以保持自然承接，例如：

> 前面的例子只用了两个取值，现在将它推广到有限多个取值. 设〔变量及其取值〕，并以〔相应概率〕作为权重，则〔本段要定义或求出的量〕可以写为：

这段写定了特例到一般设置的转场、两个设定的关联和公式的引入。中间内容仍按当前阶段保留占位，填入时沿既定关系接续。

## 3. 前后句的承接对象

先确定本句谁做什么、陈述什么状态或关系，再选择怎样承接前文。前文已经出现的对象可以放在主语、宾语、状语或回指中；承接旧信息不要求把它放到句首。说明作者怎样改稿时，“我需要逐处修改这些笔记”既接住了笔记，也接住了前文的“我”，通常比“这些笔记需要由我逐处修改”直接，同时保留了必要性的语气。

连读时核对主语、讨论对象和观察范围是否变化。可以重复名称、用代词或省略，选择依据是读者能否跟上实际动作及所指；同一承担者连续做事时不必每个分句重新点名，换了承担者就按需要说明。D1的话题链研究帮助检查对象与回指，不规定旧对象必须充当下一句的主语，也不规定所有句子都由人开头。

在骨架中写出“上述讨论”“这个条件”“由此得到的均值”等词时，指出它们具体回指哪一处。一个指代可能同时落到两个对象上时，恢复名称。叙述在实际结果、观察者已知信息和作者全貌之间切换时，写明观察立场，避免读者刚被告知结果，又被说成结果未知。

方法说明中的动作也要接续。写“检查、处理、完成”时，确定检查什么、会辨认出哪类问题、发现后怎样修改，以及修改结果如何供下一步使用。按本篇需要写足这一段联系，避免列完检查项目就跳到“因此完成”。它可以在复句中展开，也可以借具体例子说明，不强制拆成四个步骤或每段都走一遍。

公式也参加承接。公式前确定正在定义或计算的对象，以及“写为”“得到”“满足”等具体动作；公式后使用已经得到的对象继续解释。不要把完整的设定切成几句后，再让一个孤立公式负责替作者串起关系。

## 4. 主干、词序与共同成分

先找主要谓语，核清是谁在做这件事，或什么对象具有所说的状态与性质，再安排对象、条件和修饰语。叙述有明确承担者的写作、研究或操作过程时，优先让承担者直接完成动作，不惯用“内容需要得到处理”“问题可以由作者解决”等表达推迟主要动词。第1版就要写定这些主干，不能只在旁注里说“主体明确”。

| 句子的实际任务 | 组句选择 |
|---|---|
| 说明已知的人或机构怎样行动 | 优先采用“作者核对数据、补上例子，再修改结论”这类连续动作；前文对象仍可放在宾语位置 |
| 动作转交另一人 | 在交接处点明承担者，如“审读者指出缺口，作者据此补上解释”；不要从“理由无法取得”直接跳到省略主语的“就回查草图” |
| 描述对象的状态、遭遇，或施事未知且无需追查 | 可以保留被动、受事话题或无主句；例如“备份已被删除，日志未记录删除者”。不能为了主动表达编出删除者 |
| 延续某对象或作对比、交代归属 | 按上下文保留话题前置，如“这本书我读过”“本文由 Agent 撰写”；不把所有前置都当成宾语倒装错误 |

主动表达是当前过程说明的默认选择，不是通用于所有汉语句子的语法禁令。也不机械删除“把”字句，或反复添加“我们”“作者”制造新的生硬格式。G1、G2和G8提供主谓配合、省略与共同成分的辨析；共用一个主语时，要检查后面的每个动词仍由它承担。

主干确定后，再按G3、G4安排时间、条件、范围和其他修饰语，使它们贴近所管的内容。避免先堆一串名词或“怎样……”小句，等到句尾才补“需要处理”“尚未确定”。例如在“我们知道要写哪些内容”之后，可接“但还没确定怎样把它们接成段落”，让同一个“我们”连续承担“知道”和“确定”。调整词序要保留原有范围、焦点与证据身份。

主干清楚以后，还要看本句重点。介绍一个新对象时，先让读者认出它，再补履历或条件；承接已有对象并着重报告结果时，不让次要背景隔在对象与结果之间。G9〈层次〉对长修饰语给出了两种不同安排，取舍正取决于当时要突出主语还是谓语。不能把“重要信息及时出现”简化成一律把宾语前置，或一律写成人名起句。

## 5. 句子的分合与长短

将一项完整设定拆成几个短句，有时会使读者反复重新起步；把几个不同层级的说明硬串在一起，又会使句子混杂。先判断各部分是否服务于同一表达动作，再决定分合，不能以长短本身判优劣。

G9〈层次〉中的修改既有拆开混杂长句，也有增加关联成分、重复共同部分来显出关系。用于骨架时，给长句划清主要关系和从属内容；前提很长、迟迟到不了主要判断时，可先完整交代前提，再用明确的回指接主要判断。需要共用成分时核搭配，需要重复时保留能帮助读者把握层次的重复。

遇到多层抽象名词，先尝试直接叙述有据的动作。假定上下文已确认审读者负责找问题、作者负责修改且两项工作均已完成，就可以直接写“审读者已找出稿件的问题，作者也已完成修改”，避免绕成“问题识别和修改工作的完成”。改句须保留原来的分工、情态和完成状态。成熟术语或持续讨论的概念仍可保留：讨论检验程序时，“兼容性确认”可以作为名称；说明操作时，“先检查旧客户端能否按原来的方式使用接口”通常更直接。

删冗按语义贡献判断，不能见同字就删。“需要完成”与“已经完成”、可能与事实、数量与比例、必要与充分条件，都不能在顺句时互换。读者尚未获得的中间内容也不能为求短而省去；确需补足时沿第1节回到材料。G9及第五讲〈烦冗〉〈苟简〉须合起来使用，不把旧例中的某种删法当作通用词表。

插说、括号和长修饰语只能在不打乱主结构时使用。需要说明的一段经过，可以在骨架中改为独立陈述位置；若拆开会丢失前文话题，就连同前后句重新安排，不机械拆短。

## 6. 教材语气与作者引导

作者可以带领读者考虑一个对象、作一项假设、推广已有结果或比较两种情形。“现在，让我们……”“考虑……”“设……”“记……”在完成这些动作时可以自然使用。这些表达是否保留，要结合当前内容和上下文判断，不能按词面列为废话。

区分具有内容的引导和重复播报。例如从特例转入一般情形、先选定一个条件再计算，改变了读者的观察范围或操作；在步骤已明确后反复说“下面我们继续学习”，可能没有新增作用。检查引导句实际带读者做什么，再作删改。

用户示范确定了当前数学讲解可以采用的自然语气，不要求每节都用同一个开头。报告、参考记录和操作说明仍按各自对象与读者选择语气。译写时保留原材料的精确关系，中文句法重新组织；被动句或名词化只按当前话题的作用判断，不见词即删。

## 7. 标点与第1版的交付

先按句子结构确定主干、分句和插说的边界，再安排停顿。普通连接词不自动带后逗号；“常常”“往往”“通常”作状语时也一般跟谓语连读。“一般来说”这类句首评述短语，可以按实际语气用逗号领起整句。两种位置分别判断，避免把减少机械停顿执行成所有衔接表达都不能带逗号；连同整句选择位置和分合，不按词面批量删标点。

| 自拟对照 | 改动依据 |
|---|---|
| “但是，换个题目，同类问题仍会出现。”改为“但是换个题目，同类问题仍会出现。” | 转折词直接引出所接内容；保留题目变化这一条件之后的分句停顿。此处采用用户偏好的连读写法，不把所有“但是，”都判为语法错误 |
| “如果，作者省略了理由，读者就得自行补全。”改为“如果作者省略了理由，读者就得自行补全。” | “如果”与所引导的条件连读，逗号放在完整条件分句之后 |
| “虽然，例子还没填完，但是，作者已经安排好了句序。”改为“虽然例子还没填完，但作者已经安排好了句序。” | 两个关联词各与自己的分句相连，逗号分隔让步与后续判断 |

必要的条件分句、插说、并列分句或独立提示语仍可形成停顿。G5〈句号、逗号〉直接讨论了句首连接词的连读与有需要时的停顿；N1提供逗号的一般职责，没有逐名规定这些连接词。当前偏好是减少无实际作用的停顿，不能写成“中文一律禁止关联词后有逗号”，也不能据此断言此类用法都来自英语。外部引文和用户原话按其原有标点保留。

连续设定可用逗号和关联词组织；复杂的同层分支可用分号；一句主要意思完成后用句号；“写为：”一类表达使公式成为前句期待的后续内容。不要用逗号替代尚未确定的主语或句间关系，也不要仅凭呼吸、字数或英语词序安排标点。

标点还要服从整句的层次与管辖范围：

- 冒号后面的内容应落实它所提示的解释或列举；后文转入另一个意思时，重新确定句界。不能见到“说”“例如”就加冒号。
- 插说和补注结束后，读者须能接回原句。承重解释安排在正文适当位置，次要说明才按作用放进括注；不能靠一串括号掩盖尚未理顺的主线。
- 分号用于需要区分的句内层次，不按前面已有几个逗号来分配；并列短语与并列分句也不能混用一套停顿。
- 问号由整句是否发问决定；引号区分直接引述与转述。引文和括注内外的点号须结合其是否独立成句处理。

具体形式按N1正文及附录核对。旧书帮助分析表达作用，现行标准与项目排版约定决定当前用法；数学符号另依专业含义处理。若标点无法使关系清楚，回到草图重组句子，不能让符号替代缺失的文字。

第1版除段落内容安排外，还要能直接读到本句谁做什么、怎样接回前文、哪里切换主语、关联词引导哪一段内容，以及实际停顿放在哪里。中间说明保留具体语义占位，主干、关键语序和连接词后的连读或停顿则实际写定。不得把“主体明确”“语法自然”“此处承上启下”留作唯一说明，也不以把说明全部写完来替代组织安排。

原有关键句可以按完成程度修订；中间内容仍用明确占位表示。占位的前后连接词和标点应已写入骨架，使填充者只补内容，不重新选择句群组织。

后续沿实际骨架核读者能否接续理解，不能让职责旁注替正文补讲理由。专项反馈、重要保持判断及记录范围统一见 [专项检查](specialist-checks.md#2-后续版本的专项检查)，最终草图的验收与填充边界沿 [workflow](workflow.md#3-草图修改与最终验收)。
