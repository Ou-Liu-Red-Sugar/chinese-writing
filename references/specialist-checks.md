# 写作方法调用与专项检查

本页把现有写作能力接到第1版生成及后续骨架修订。具体方法由 [composition](composition.md) 与 [qualification](qualification.md) 定义，文献及实际支持范围见各自来源记录；不再复制一套写作原则。

## 1. 第1版生成时使用的方法

作者先取得第0版思想与体现安排、当前读者、材料和内容职责，实际读取以下对应方法，再据此写第1版。不能先凭习惯生成骨架，然后仅在记录中补上“已调用skill”。

| 写作能力与方法入口 | 第1版中必须作出的具体安排 |
|---|---|
| [篇章与章节安排](composition.md#3-全篇次序)、[章、节与段落](composition.md#4-章节与段落) | 哪些思想组成一节，哪些连续内容放在同一段，依什么关系先后展开；节与段不按知识名词或材料篇数机械划分 |
| [材料取舍与详略](composition.md#2-选材与详略) | 每段写哪些内容、展开到哪一步，例子/反例/公式具体承担什么；背景、关键过程和参考材料分别放在哪里 |
| [句子组成与起承转合](sentence-construction.md) | 确定前句已交代什么、后句怎样承接及其间需要的解释，写出实际起句、回指、关系表达、句内层级和公式入口；中间内容占位应有确定含义，组句决定不能占位 |
| [话题和主干](composition.md#5-句子主干与话题)、[词序与范围](composition.md#6-词序与修饰范围) | 实际起句和衔接句从什么对象接起，把什么留给下一句/段；明确中间内容的主体、条件和范围，暂不展开成所有完整句子 |
| [标点与语义范围](composition.md#9-标点与语义范围) | 用实际冒号、分号、逗号和句号划定解释、并列、从属及完成关系，确定这些标点之间应当放什么内容；标点参与设计，不只是成稿排版 |
| [必要限定](qualification.md#2-在草图中逐命题处理) | 材料涉及条件、来源主张、预测或未知时，安排其所在命题及范围；具体中间句尚未展开，也不能把证据身份留到正文再补 |

在第1版旁记录实际采用的方法及它改变了哪项安排，例如“依据材料取舍方法，将实例放在定义之后，用来区分两种原先混淆的对象”。只记录承重选择，不为每句增加引用或重复方法全文。

## 2. 后续版本的专项检查

第1版形成并保存后，按下面的专项审读骨架。适用项目都要有真实结果；可由同一执行者合并承担，也可按具名难点分工，不固定人数、轮次或每项问题数。后续修改后重点复核受影响项目及其上下游，不机械把全部专项重跑。

| 专项 | 检查对象及应回答的问题 | 返回内容 |
|---|---|---|
| 篇章、章节与内容安排 | 全文中心和任务是否明确；章节划分及段落次序是否符合思想关系；材料在哪里需要、详略是否落在所要解释的地方 | 定位需要移动、合并、拆分、展开或删去的具体内容，说明它如何影响理解或判断 |
| 段落与前后衔接 | 本段已建立什么；后段使用的对象、原因或条件是否已有安排；话题更换或解释层级变化是否接得上 | 连读实际段末、段首及必要上下文，指出后文承接哪项已有信息、缺少哪一步；按理解依赖调整位置或补足有据内容 |
| 句子组成、词序与标点 | 前句留下的对象/判断/动作怎样成为后句的出发点；关系是否有依据且已表达；是否缺少解释或动作；主语、句序、标点及公式入口是否相配 | 引用实际前后句，按 [组句方法](sentence-construction.md#2-按关系组合分句) 区分关系表达、中间内容或依据缺口，给出完整受影响句群的改法或保持理由。不能只查单句病句、连词数量或段落主题；未填文字只核安排，不冒称已逐句通顺 |
| 必要限定与防御性措辞 | 条件和来源身份是否落在对应命题；局部未知是否扩大到全文；谨慎表态是否重复；删改是否提高了确定性 | 逐项给出保留、局部化、改具体条件或删除的依据，并核修改后判断的范围 |

长修饰语、名词化或译写表达的问题按 [composition 第7–8节](composition.md#7-长修饰语与名词化) 并入句法专项。数学、事实、计算和引用核对由所属领域方法承担，不能代替中文专项；中文修改引起事实或公式变化时，要核相应下游。

审读先沿骨架正文和明确占位读，再看段落职责与作者解释。遇到关系跳变时，先指出读者到这里已知道什么，再看后句要求他知道什么；若两者之间还需审读者口头补讲，检查那项内容是否已进入骨架、是否有材料支持。前后文已经自然承接时，保留其句序、回指或省略，不为检查而逐句添加连词。连读覆盖全稿，记录集中在实质问题和重要保持判断，不规定问题数。

不适用的项目说明具体原因。例如一份不含不确定判断的短参考表，仍核单位和范围，但无需制造防御性措辞问题。检查没有发现问题时，引用当前骨架中的实际文字说明承接对象及关系为何成立；“各项均通过”或复述作者的段落意图不构成依据。

## 3. 反馈与骨架修订

原始反馈指明草图版本、专项、具体位置、原片段、问题或保持理由、方法依据及建议。作者按实际关系合并重叠意见，保留每项处置和受影响位置。观点分歧由Lead依据材料、读者和文献方法裁决，不按人数投票。

修订可以改变章节、内容落点、段落、衔接句和标点。中间内容仍可以保留明确占位；后续版本的目标是把这些关系彻底确定，不能只靠不断扩写中间句子制造进展。

最终验收沿 [workflow 第3–4节](workflow.md#3-草图修改与最终验收)，核本轮适用专项是否实际完成、意见怎样改变或确认当前骨架。骨架稳定后再填正文，成稿另核已写出的中间句子和此前安排是否一致。记录不进入读者正文。
