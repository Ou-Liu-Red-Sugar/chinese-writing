# 写作方法调用与专项检查

本页把写作方法接到第1版生成及后续骨架修订。篇章方法由 [composition](composition.md) 定义，实际组句由 [sentence-construction](sentence-construction.md) 定义，必要条件及防御性措辞由 [qualification](qualification.md) 定义；来源和采用范围见 [literature](literature.md)。阶段、冻结与留档要求统一沿 [workflow](workflow.md)，这里不增加阶段或记录体系。

## 1. 第1版生成时使用的方法

作者取得第0版思想安排、读者、取材认识与资料需求后，先读对应方法，再组织第1版。此时取材限于服务草图，需深查的内容按[取材与深挖](workflow.md#取材与深挖)留占位。新写或实质改写入口时用[开篇方法](openings.md)把标题与入口写成实际语句，不能生成后只补记“已调用skill”。

| 写作能力与方法入口 | 第1版中必须作出的具体安排 |
|---|---|
| [篇章次序](composition.md#3-全篇次序) | 读者先知道什么，各项认识怎样先后或并列建立；开头如何进入，重点何时出现，结尾完成什么；不按资料取得次序或固定格式排列 |
| [材料取舍与详略](composition.md#2-选材与详略) | 每段使用哪些材料，关键过程展开到哪一步，次要内容保留什么联系；例子、反例、公式或图表具体帮助读者理解什么及放在何处 |
| [章、节与段落](composition.md#4-章节与段落) | 哪些内容共同完成一段，前段留下什么、后段接着增加什么；对象、观察范围或比较维度怎样转换；所需解释写进骨架 |
| [句群、主干和词序](sentence-construction.md) | 写定实际起句、主要动作或关系、承担者转换、共用成分及必要回指；中间内容占位有确定含义和语法作用，组句决定不能占位 |
| [分句关系与句群重组](sentence-construction.md#从分句关系重组句群) | 还原信息与状态，找出前句留下的阅读期待及后句回应，写定句序、层级、完整句式和有作用的小词；常用表达沿实际关系选择 |
| [情态、动作进展与语气](sentence-construction.md#从分句关系重组句群) | 明确是在讲通常行为、假设情形还是实际结果，给出动作和参照时点的关系；比较有字/无字的完整表达，写足“会、还、已经、就、才”等在该句中的实际作用 |
| [标点与句界](sentence-construction.md#7-标点与第1版的交付) | 依主干、分句、插说和引入范围同步安排标点；写定哪里连读、哪里停顿，公式怎样进入；连接词不默认带后逗号 |
| [必要限定](qualification.md#2-在草图中逐命题处理) | 条件、来源主张、预测或未知落在对应命题，范围清楚；中间句尚未展开，也不把证据身份留到正文再补 |

在既有草图记录中简记承重选择及采用理由，例如“先保留同一组数据说明分母，再改变计数对象，使读者看清两种口径的区别”。不为每句另列方法表。句序、话题与连接词共同承担接续，既要表达清楚，也要让语气和推进自然；不因关系可以推知就省略有用的连接，不用连词密度代表组织程度。

## 2. 后续版本的专项检查

Lead先按[阶段接收检查](workflow.md#阶段接收检查)确认实际产物属于所交阶段；首次骨架已提前写成全文时先退回，不因内容已经齐全就启动全面专业审查。接收后，文字审读与专业审查分开委派，按当前稿件已有内容调用。完整文章涉及专业事实、机制或计算时，分别使用实际执行者，不让同一位执行者在一次通读中兼任。各角色读取本次用户要求、项目适用约定和对应方法，注明本轮具体输入版本与范围，独立保存意见后再由Lead处理。普通问答和短小局部改句按其实际范围工作，不启动整套分工。

| 草图的实际完成程度 | 当前要检查什么 | 此时不要求什么 |
|---|---|---|
| 第0版思想与呈现安排 | Lead核取材是否适度，并沿[起承转合](composition.md#第0版的起承转合)走读全篇；超出取材深度的疑点登记待核 | 不提前逐表取数或委派深挖，不把思想图当成稿审句法，不以知识点齐全或四个标签代替文气安排 |
| 第1版形成与接收 | 文字角色核实际起句、承接、句序、标点与资料需求；Lead核是否交出并符合本阶段 | 此前只取材、不深挖，不以数值缺失判失败；用户要求停在此版时仍等待反馈 |
| 第1版之后的深挖与骨架修订 | 按已定需求搜集原件；专业角色核实际采用的主张、输入、机制和计算，文字角色核怎样接入骨架 | 不让材料数量决定主线，不按版号重查未改内容，不让算术正确代替文字意见 |
| 最终草图与填充 | 冻结前核已定专业内容及局部填充的确定输入；填后核实际采用与固定骨架对应 | 不把待设计的机制、待选数字藏在局部填充中，不补造此前不存在的审查结果 |

第1版接收且范围允许继续后，深挖与适用文字审读可以并行。专业审查按已具备内容执行，不能借核承重前提在取材阶段先完成整套研究。早期未执行专业核验不构成该版失败，也不能登记为正确性已通过。

| 角色 | 接收的材料 | 要作出的判断 |
|---|---|---|
| 文字审读者 | 首判取得文体、读者已有知识、题目与使用场景、当前骨架或成稿、实际前后文，以及篇章、句法和限定方法；定稿时再取得已解决的专业意见与必要语义约束 | 读者从文字中得到什么，开头能否建立对象与关系，内容为何在此出现，句段怎样接续，解释是否兑现；最终决定详略、表达精度、词序与标点，并负责最后文字定稿 |
| 专业审查者 | 当前已具备具体论述的稿本或片段、任务范围、原始资料、计算输入和专业方法；校准题可取得判别依据 | 本轮已有事实与来源是否对应，定义、机制、推导、计算和条件是否成立，证据身份与结论强度是否一致；返回正确内容、依据与必须保留的条件，交文字角色组织 |

文字审读首轮不接收第0版意图表、段落职责旁注、作者自评、既有审查结论或参考答案。调度者从草图中取得供读者阅读的实际文字，保留标题、次序、标点、公式、图表和明确的内容占位；不为送审润色或补句。占位的具体含义若写在单独字段中，应带上该字段，只去掉作者对安排好坏的解释。普通成稿直接送原文。由此取得可连读的稿件即可，不为隔离输入强造另一套版本系统。

先保存文字首判，再按具名疑点补给来源或作者意图，用来判断应怎样修订；后取得的解释不能追认原文已经说清。已看过这些材料的执行者如实登记暴露，不称为未提示首判。独立执行者暂不可用时，可另设阶段自查并标明身份，独立审查仍记未执行；不得由作者代写另一位的意见。

文字审读负责以下方面，可以在同一角色的一次连续阅读中完成。专业审查另留结果，不以计算问题覆盖这些专项。

| 专项 | 检查对象及应回答的问题 | 返回内容 |
|---|---|---|
| 篇章、章节与内容安排 | 实际骨架如何落实第0版的起承转合；读者的疑问怎样推进与回应；转进是否有来由，主例与旁支能否回收，详略、节奏及语气是否共同服务中心 | 定位影响全篇连续性的断点与需移动、合并、展开或删去的内容；安排已成立时指出实际依据，不能以局部句句通顺代替全文贯通 |
| 段落与前后衔接 | 本段实际交代什么，后段要求读者知道什么；前文提出的比较或解释是否兑现；对象、视点、条件和层级的改变能否跟上 | 连读具体段末、段首及必要上下文，指出承接的已有信息或缺失的一步；有据地重排或补足，不让作者旁注代替正文关系 |
| 句子组成、词序与标点 | 句群是否完成一项清楚的表达；主干、主语及修饰范围是否配合；重点是否被次要内容隔断；关联词、回指、省略和停顿是否各有作用 | 引用实际句群并核原意；未填文字只核其安排，中间说明写实或修订后沿[句界方法](sentence-construction.md#7-标点与第1版的交付)重核顿号、分号和句号，不把占位标点当作已经定稿 |
| 情态、动作状态与语气 | 一般说明、假设及实际观察是否分清；动作处在未开始、持续、等待还是完成状态；小词与时间、条件、否定及预期如何配合 | 连读有字和无字的句群，指出损失或增加的具体意思与语气；既恢复承重省略，也核自然表达是否改变原事实，不以大意仍可猜到判通过 |
| 必要限定与防御性措辞 | 条件和来源身份是否贴合对应命题；局部未知是否被扩大；谨慎表态是否重复；删改是否改变确定性或适用范围 | 给出保留、局部化、改具体条件或删除的依据，并核修改后判断的范围 |

文字审读先按顺序读全稿，标出首次需要停下来猜对象、用途、理由或前提的位置，再回查以下关系：

- **接题、点题与阅读需要。** 按[开篇验收](openings.md#5-依据实际开头验收)，从标题读到实际开头及下一部分：题意的哪项关系已经出现，为什么值得继续读，后文是否回应了开头引出的需要。不能用作者意图、任务说明、数字出现或“本篇介绍”代答。正文还须沿标题主线推进并扣题，不能只在开头重复题名；已有前文建立需要时直接承接，不强加重复动员。
- **句段的承接。** 在关键转换处，指出前文已经建立的内容和下一句开始使用的内容；缺少的专业前提或中间关系要定位到具体句子。数学熟练不等于熟悉金融、会计或制度。审读者调用自己的知识才能接上的地方，不能登记为稿件已解释。
- **解释的兑现。** 前文提出的问题、比较或过程，后文是否实际展开；列数字、给限制、指向下一篇，不能自动完成本篇承诺的解释。区分需要专业判断的真伪与文字中尚未呈现的关系。
- **语言的组织。** 沿[句群重组方法](sentence-construction.md#从分句关系重组句群)指出前句让读者取得什么、继续期待什么，后句怎样使用或回应；核主语、对象、动作状态、层级与停顿是否接续。对生硬处做有字/无字比较，具体说清小词怎样改变情态、完成状态、参照时点或语气，不给一个词固定一种职责。表达密集重复时，沿[常用候选](sentence-construction.md#常用衔接表达)选择合适说法或重组重复设定，再按[完整讲解与适度从容](sentence-construction.md#完整讲解与适度从容)连读；有用的铺垫、呼应和停顿可以保留。给出实际修改后的句群并核原意，分别判断语法、内容与阅读感受。

反馈保存首次卡住的位置及理由，区分可从原文找到的解释与自行补出的解释。安排成立时给出实际前后句及成立依据；无需逐句制表、固定发现几个问题或额外列一套分数。第1版尚未写出的中间句子只核其含义与安排，不要求提前成稿。

有作用的重复、长句、被动、前置、省略或停顿可以保持。只在当前争点或重要保持判断处说明其作用，不让普通正确句式都承担额外记录。连读覆盖全稿，记录集中于实质问题及重要保持判断。没有发现问题时，用当前骨架中的实际片段说明安排为何成立；笼统的“均通过”和复述作者意图不构成检查结果。

不适用的项目说明具体原因；例如短参考表仍核名称、单位和范围，却无需制造议论转折或防御性措辞问题。长修饰语、名词化、译写及公式引入并入句法专项，处理方法见 [句子组成](sentence-construction.md)。没有待核专业主张的文章可说明专业审查不适用，不能把普通文字偏好包装成事实核验。

两位审查者可以发现同一位置的不同问题。例如文字审读可指出“读者尚不知道折旧怎样进入利润，下一句就要求比较利润与现金”；专业审查再核这项关系怎样表述才成立。文字审读发现疑似事实错误时标出并交专业审查，不把本轮改为查账。专业审查给出问题位置、正确关系、依据与必须保留的条件；可以提供措辞候选，但由文字角色决定如何进入文章，不直接覆盖已审文字。

## 3. 反馈与骨架修订

原始反馈分别注明角色、执行者、输入版本、已暴露材料、具体位置与片段、问题或保持理由及建议。作者先修订草图，Lead归并重叠问题、解决事实分歧并保留处置依据，随后交文字角色完成最后一轮编辑。文字与专业意见共用同一处置记录即可，但不能归并成一个“综合通过”。专业正确与读者可理解分别满足，不按人数投票。

修订可以改变思想落点、章节、材料位置、详略、段落、衔接句及标点，目标是使组织和句间关系彻底成立。中间内容仍可保留具体占位，不靠每轮多填正文证明进展；无必要改动时保留已成立的文字，不凑版本。

最终验收沿 [workflow 第3–4节](workflow.md#3-草图修改与最终验收)，分别核文字意见和实际采用内容的专业意见。此前已核且未改的内容沿用原结果；新增或改动的内容核相应影响。开头仍意义不明、承重衔接或必要解释仍缺失时，不能用专业正确抵消；事实或机制错误也不能用文字流畅抵消。文字角色完成最后编辑，Lead核其结果与处置后冻结骨架，不另写一遍专业审查腔的定稿。修改后的复核只覆盖受影响职责与上下游，不机械重跑两套全文审查。

## 4. 文字定稿与精度

专业意见处理后，最后一轮始终交文字审读者。它连续读稿并直接完成定稿：选择术语解释到哪一层、过程展开到哪一步、条件放在哪里、哪些细节移到脚注或附录，以及数字采用何种单位和显示精度。精度由读者任务决定，不因来源给出更多小数位或专业审查列出更多区分，就全部搬进正文。

表达精度服从已核事实与计算关系。计算保留核定输入；正文可以在不改变比较、判断或复算用途的范围内取整、用量级表达或省略无关明细。需要读者复算时提供足够有效位数或原始输入入口；涉及临界值时不取整到改变结论。必要条件与证据身份保留在对应命题中，重复限制和不影响本篇理解的专业分支由文字角色删减或移置。

文字角色若无法判断某项删改是否改变专业含义，提出具名问题交专业角色定点回答，再由文字角色落笔。专业角色发现后续错误也采用同一方式，不直接留下末轮改稿。Lead负责范围与采用，核结果不代替文字角色再改句；需要实质修订就退回相应职责，最后仍由文字角色收尾。

冻结后的填充只补确定的局部内容。完成填充及必要的内容、算术和对应核对后，由文字角色最后通读实际正文；若需改固定句序、解释或标点，按workflow退回草图再定稿。最终交付版本须包含这次收尾，随后只作不改文字的保存或同源生成。

主次、进入次序、必要解释及例子职责均须在冻结前确定；填充者只补局部内容。填入后若还须移动材料、改变句序或补承重解释，退回草图修订并重新验收，不能静默修改固定部分。记录留在既有过程材料中，不进入读者正文。
